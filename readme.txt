A custom owner-direct rental directory theme for Our Villages Rentals.

== Description ==
OVR Villages is a custom WordPress theme for a local owner-direct rental advertising platform focused on The Villages, Florida.

== Resources ==
Tailwind CSS CDN is loaded from https://cdn.tailwindcss.com.
Atkinson Hyperlegible Next and Material Symbols are loaded from Google Fonts.
Remote demonstration images in the homepage template are generated/static design references from the supplied Stitch export.
